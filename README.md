# MinimumSpanningTree
This project primarily serves as an implementation of Prim's Algorithm to find a Minimum Spanning Tree of a graph, if possible. App.java, in particular, demonstrates this where node values are integers and edge weights are automatically calculated as the absolute difference between the two nodes. However, the code for acceptable node values and calculated edge weights can be easily modified. Note: The graph appears directed for future implementations of Dijkstra's Shortest Path Algorithm, but Prim's Algorithm treats the graph as undirected.
