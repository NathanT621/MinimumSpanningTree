# MinimumSpanningTree
This project primarily serves as an implementation of Prim's Algorithm to find a Minimum Spanning Tree of a graph, if possible. App.java, in particular, demonstrates this where node values are integers and edge weights are automatically calculated as the absolute difference between the two nodes. However, the code for acceptable node values and calculated edge weights can be easily modified. Note: The graph appears directed for future implementations of Dijkstra's Shortest Path Algorithm, but Prim's Algorithm treats the graph as undirected. See: ![MST screenshot](assets/mstScreenshot) ![Prim screenshot](assets/primScreenshot)
<br>Technology used: Java, JavaFx
<br>The second part of this project is a sample application of the MST. By taking 7 key NBA stats of all 30 NBA teams for the 2025-26 season from NBA.com, calculating each team's z-score for each respective stat, and taking the Euclidean distance between each team, we obtain a K_30 graph, i.e. we can model each team as a node, with 29 incident edges per node, and edge weights between two nodes (teams) representing their statistical variation. We then apply Prim's Algorithm to obtain a similarity network. We can examine clusters and edge weights to understand which teams are statistically similar in an effort to predict outcomes of future games. <br> See: ![NBA Prim Application screenshot](assets/NBAGraph)
<br>Technology used: MATLAB, Java, Excel
